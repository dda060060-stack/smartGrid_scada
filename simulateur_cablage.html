      Guide technique — Conception & Simulation
      
        
      
      
      
      
        Commandes du plan de travail :
        
        
          
      • Câbler : cliquer sur une broche source puis sur une broche cible (routage orthogonal 90° automatique).
        • 
          
      • Menu contextuel : clic droit sur un composant pour ouvrir sa documentation broches, le pivoter, le dupliquer ou le supprimer.
        • 
          
      • Supprimer un conducteur : double-clic sur le fil ou touche Suppr.
        • 
          
      • Navigation : molette pour zoomer, glisser sur le fond pour déplacer la vue (Pan), Ctrl+Z pour annuler, Ctrl+S pour enregistrer en JSON.
        • 
          
      • Vérification électrique : contrôle en continu le Buck LM2596 (+5V VIN), le pont diviseur 10 kΩ / 10 kΩ sur ECHO, le pull-up 4,7 kΩ DS18B20, les canaux ADC1 (GPIO 32-39), le bus I2C (GPIO 21/22), le câblage série ACS712 et la masse GND commune.
